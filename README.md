# PLANET — Cinematic 3D Experience 2.0

Интерактивное путешествие по одной непрерывной 3D-сцене. После вступления длительностью 6,2 секунды камера останавливается на общем виде. Дальнейшие перелёты запускает пользователь.

## Запуск

Откройте `launch.cmd`: в этой рабочей копии подготовлен переносной Node.js. Или используйте установленный Node.js 22+:

```sh
npm install
npm run dev
```

Vite выводит адрес в терминале (обычно http://127.0.0.1:5173; занятый порт автоматически заменяется следующим).

```sh
npm run build
npm run preview
```

## Управление

- Нажмите на Солнце или любую планету в общем обзоре либо выберите объект в меню.
- Стрелка вправо открывает полный вид, затем крупный план, затем следующий объект. Работают также клавиши ← / →.
- Стрелка влево возвращает по истории посещений. После прямого выбора Земли возврат ведёт к общему обзору, без промежуточного просмотра предыдущих планет.
- Кнопка общего вида возвращает к системе. Escape закрывает диалог или возвращает к обзору.

Прокрутка не управляет камерой. После прибытия она остаётся неподвижной; тела медленно вращаются. У всех девяти объектов два разных информационных блока: описание и характеристики в полном виде, отдельный факт с объяснением в крупном.

## Камера и сцена

`src/animations/CinematicCameraController.tsx` — единственный владелец камеры. Один GSAP timeline согласует движение и появление текста. Новая команда отменяет текущий timeline и строит путь от фактических позиции и quaternion камеры.

`cinematicPath.ts` рассчитывает индивидуальные траектории Catmull–Rom. Перелёт между объектами состоит из отхода, перемещения и продолжительного приближения. Логарифмическое изменение расстояния распределяет рост планеты по всей заключительной части пути. Обычные межпланетные перелёты занимают около 5,9–6,6 секунды; переход к крупному плану — 3,6 секунды. Геометрическая проверка учитывает защитные области всех тел и колец Сатурна.

`navigation.ts` хранит историю и текущую цель независимо от завершённого ракурса, поэтому быстрые повторные нажатия не создают очередь старых анимаций. Прямой выбор Нептуна строит один маршрут к нему.

Один Canvas и одна PerspectiveCamera сохраняются между этапами. Все планеты постоянно присутствуют в сцене; их прозрачность не меняется при переходе. Только вступление постепенно проявляет объекты. Кадровое обновление вращает тела и обновляет материалы, но не конкурирует с GSAP за камеру.

Земля использует дневную и ночную карты, нормали, маску отражения океанов, отдельную оболочку облаков и их тени. У Сатурна прозрачные кольца и аналитические тени колец/планеты. Солнце имеет потемнение к краю и мягкую корону. Источники локальных текстур и лицензия описаны в [TEXTURES.md](TEXTURES.md).

Набор 4K/2K выбирается при загрузке с учётом ширины экрана, памяти и Save-Data. DPR ограничен 1,6. При reduced motion вращение отключается, перелёты сокращаются. Композиция адаптируется к узким и коротким экранам. Manrope используется в интерфейсе и основном тексте, Space Grotesk — в английских названиях, Cormorant Garamond — в атмосферных фразах. Шрифты загружаются через Google Fonts с системными fallback.

## Проверки

```sh
npm run test:paths
npm run test:e2e
npm run test:route
```

Браузерные сценарии требуют работающего dev-сервера и установленного Microsoft Edge. По умолчанию тесты используют порт 5175; другой адрес задаётся переменной `BASE_URL`, например `$env:BASE_URL='http://127.0.0.1:5173'` в PowerShell. Отдельная мобильная проверка: `npm run test:mobile`.

В development доступен читающий `window.__planetCamera.snapshot()` и метод проекции границ объектов `bounds(index)`. В production этот интерфейс не устанавливается. Отчёты и скриншоты: `test-results/interactive/`. Результаты и границы проверки: [CHECKS.md](CHECKS.md).

## Источники и ограничения

Научные тексты сверены с [NASA Science](https://science.nasa.gov/solar-system/); ссылки для каждого объекта находятся в справке и `src/data/stories.ts`. Числа округлены, диаметры экваториальные. Текстуры Solar System Scope / INOVE распространяются по [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Локальные 4K-карты подготовлены из исходных 8K/4K; Уран и Нептун используют доступные 2K-карты.

Масштабы и положения адаптированы для композиции, это не эфемериды. Освещение, рассеяние и тени приближённые, рельеф не является детальной геометрией. В исходных текстурах встречаются усиленные цвета и заполненные авторами участки. На физических телефонах и разных GPU производительность не измерялась; стабильные 60 FPS и фотореализм научных рендеров NASA не заявляются.
